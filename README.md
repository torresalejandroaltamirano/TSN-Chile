# TSN Chile

Plataforma local de Trabajo, Servicios y Negocios para Copiapó, La Serena y el norte de Chile.

## Principios
- Buscar empleo y consultar servicios: gratis.
- Avisos básicos: gratuitos y sujetos a revisión.
- Monetización: destacados de 30 días, publicaciones patrocinadas, planes para empresas/profesionales y publicidad local.

## Estado
Repositorio oficial para la recuperación, desarrollo y publicación HTTPS de TSN Chile.
